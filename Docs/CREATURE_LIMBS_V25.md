# Creature Limb Fidelity — v2.5

## Goal
Bring the procedural tetrapod's limbs closer to the approved illustrated
Carboniferous reference: legs must hang from the belly rather than read as
straight mechanical bars. Keep the approved muted palette, chunky native
128x96 pixel clusters, expressive face, and low-slung outline.

## Authoritative C# implementation

- New `Assets/Scripts/Anatomy/PixelLimbSilhouette.cs` computes an original,
  deterministic integer-grid two-segment leg, with root, knee, ankle, and
  upper/lower widths derived from morphological limb style and inherited
  leg length.
- `PixelCreaturePainter` now paints asymmetric upper and lower silhouette
  polygons, inset pigment, a front-side highlight, and planted digit clusters.
- Background limbs are one unit narrower and darker than foreground limbs.
  No source pixels or AI illustrations are imported.
- Walk and swim poses reuse the same immutable shoulder/hip anchors and change
  only the distal position. The movement is a simple four-frame illustration
  and does **not** implement IK or a contact/force solver.
- The existing layered composition, 128x96 sprite contract, and genotype-based
  creature layouts are preserved.

## Regression checks

`PixelCreaturePipelineTests` now includes:
1. Fixed-root, vertically ordered root/knee/ankle positions across all
   walk/swim frames.
2. Valid silhouette polygon bounds across extreme leg lengths and four styles.
3. Smaller far-side shoulder geometry with unchanged anatomical joint roots.

These tests are committed but **not executed in Unity**.

## Technical preview and honest provenance

`ERO_v25_Limb_Geometry_Audit.png` is generated by a standalone Pillow port
of the committed `PixelLimbSilhouette.Build`, `UpperPolygon`, and
`LowerPolygon` geometry. It shows isolated limbs only and is **not** a Unity
render or proof that the full procedural organism matches the concept sheet.
The code producing the geometry is committed; the image was made with a
separate drawing backend to inspect the joint locations and broad silhouette.

The approved sprite references remain the design standard. We must still
inspect true full-creature Unity output for proportion, detail, expression,
palette grouping, fore/hind coordination, and foot-to-terrain contact.

## Actual Unity QA

Run the existing Unity menu command:

**Earth: Rogue Origins > Art > Pixel Creatures > Export Full Creature Morphology Audit**

Then compare its actual C# output to the approved reference at native sprite
size and at 32/64 gameplay pixels. Fix visible differences rather than
increasing procedural variation prematurely.

## Next priorities

- A real contact-foot gait that preserves ankle placement under shifting
  body mass, instead of simply oscillating foot x-position.
- Anatomical shoulder/belly occlusion masks and distinct fore/hind limb forms.
- Hand-curated color-cluster shading that avoids tube-like shin appearance.
- A visual regression harness and actual Unity test execution before
  accepting concept-style fidelity.
