# Visual Progress v1.5 — Real Pixel Renders, Not Concept Mockups

This iteration introduces a more explicit separation between independent
experimental pixel-raster previews and outputs from the authoritative Unity C#
generator.

## Visual preview
A standalone Python preview rasterizer was run to produce five transparent
hero creatures and four walk frames at 128×96 pixels. The experiment uses
hand-authored profile curves, intentional belly/shoulder shading, grounded toes,
and synchronized tail-root contours. It is *not* a screenshot of Unity and is
not necessarily pixel-identical to the C# generator.

The preliminary image compares the earlier 12-creature starter sheet against
the experimental v1.5 terrestrial anatomy studies. Actual review should focus
on anatomical continuity, leg grounding, eye placement, belly curve and clade
differences at game size rather than enlarging them solely for aesthetics.

## New authoritative Unity capture

Run menu command:

**Earth: Rogue Origins > Art > Pixel Creatures > Export Visual Progress Board**

Or from Windows PowerShell:

```powershell
.\scripts\export-pixel-visual-audit.ps1 -UnityEditor "C:\Program Files\Unity\Hub\Editor\6000.0.23f1\Editor\Unity.exe"
```

The exporter uses `PixelCreaturePainter.RenderPixels()` **directly**, so the
render is generated by the exact game sprite implementation, and writes:
- `ValidationResults/PixelVisualAudit/actual_unity_csharp_creatures.png` —
  five curated hero creatures and four frames for the marsh crawler
- `ValidationResults/PixelVisualAudit/visibility.csv` —
  per-creature non-transparent pixel counts
- `ValidationResults/PixelVisualAudit/render.log` — Unity editor output

It produces an RGBA 640×192 pixel contact sheet and does not require a graphics
device. It can therefore run with `-nographics`. This does **not** replace a
full Unity scene/playtest screenshot.
